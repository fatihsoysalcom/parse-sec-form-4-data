# Parse SEC Form 4 Data

This Python script demonstrates how to fetch and parse SEC Form 4 filings for a specific day using the SEC's EDGAR API. It extracts transaction details such as owner, security type, transaction type, shares, and price per share.

## Language

`python`

## How to Run

1. Ensure you have Python installed.
2. Install the 'requests' library: pip install requests
3. Run the script: python parse_sec_form4.py
